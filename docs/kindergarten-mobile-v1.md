# Мобильная версия /kindergarten — пакет 1

База: 30469af610eea3ebfac226bf3b86e3b407700f4c.
Ветка: feature/kindergarten-mobile-v1.
Статус: предварительная версия, без публикации на рабочем домене.

## Изменения

Мобильный режим включён только на /kindergarten до 767 CSS px. Начиная с 768 px используется исходный AlbumCatalog; страницы школы и существующие цены/комплектации не изменяются. В герое добавлены только CSS-маркеры, сохранены тексты и фотографии. На телефоне сокращены отступы, выделена основная кнопка, преимущества компактнее. В каталоге видны все пять форматов с ценами, подробно показан один выбранный альбом, по умолчанию на 10 страниц. Комплектация, дополнения, видео и сравнение раскрываются. Данные берутся из albumPackages. Картинка показывается без обрезки, доступен крупный просмотр. Видео имеет штатные controls. Кнопка расчёта ведёт к прежней форме.

События аналитики: album_format_select, album_comparison_open, album_details_open. Наличие обработчиков не означает, что цели уже созданы в кабинете Метрики.

## Границы пакета

Не изменены остальные преимущества, процесс, отзывы, FAQ, общая шапка, закреплённая кнопка, CRM-форма и страницы школ. Нельзя считать этот пакет модернизацией всей мобильной страницы.

## Коммерческие расхождения — отдельно от вёрстки

Код базы и документ «04 — Выпускные альбомы — продукт и процессы v1.3» расходятся: диплом/грамота в 10-страничном альбоме, условия скидок на отдельные фото/видео, скидка 50% на видео для «Большой истории», минимальный школьный тираж. Мобильная доработка не исправляет коммерческие условия молча. Перед публикацией нужно сверить последние решения собственника и синхронизировать их отдельным изменением для всех устройств. Рабочую продуктовую модель нельзя заменять предположениями.

## Проверка

Добавлены TypeScript-проверка изменённых файлов и браузерный сценарий для двух реальных сборок. Проверяются ширины 320, 360, 390, 430, 767 px, выбор пяти форматов, изображения, детали, сравнение, фокус, видео controls, переход к форме с UTM. Формы не отправляются, внешние запросы браузера блокируются. Проверка 200% текста — для каталога. Геометрия исходного и изменённого десктопа сравнивается на 768/1024/1440 px, школьные страницы — на 390/1440 px. Создаются скриншоты и report.json. Наличие сценариев не равно успешному прохождению: результат определяется фактическим запуском. Safari/iPhone и реальная CRM-отправка требуют отдельной проверки.

## Выпуск

Не сливать и не публиковать автоматически. Нужны успешные проверки, визуальное согласование собственника и разрешение коммерческих расхождений. Для отката вернуть импорт исходного AlbumCatalog в Kindergarten.tsx и удалить импорт мобильного CSS/класс-маркер либо отменить коммит.
