# Инструкция по загрузке фотографий в галерею детского сада

## Структура файлов

Загружайте фотографии в эту папку со следующими именами:

### Desktop версии (основные фото):
- `1.webp`, `2.webp`, `3.webp`, `4.webp` и т.д.
- Альтернативные форматы: `1.jpg`, `2.jpg`, `3.jpg` и т.д.

### Mobile версии (оптимизированные):
- `1-mobile.webp`, `2-mobile.webp`, `3-mobile.webp` и т.д.
- Альтернативные форматы: `1-mobile.jpg`, `2-mobile.jpg` и т.д.

## Рекомендуемые разрешения:

### Горизонтальные фото (landscape):
- **Desktop**: 1200×900 пикселей
- **Mobile**: 800×600 пикселей

### Вертикальные фото (portrait):
- **Desktop**: 900×1200 пикселей
- **Mobile**: 600×800 пикселей

### Квадратные фото:
- **Desktop**: 1000×1000 пикселей
- **Mobile**: 600×600 пикселей

## Важные замечания:

1. **Нумерация должна быть последовательной**: 1, 2, 3, 4, 5...
2. **Пропуски допустимы**: можно иметь 1, 2, 5, 7 (но не рекомендуется)
3. **Формат WebP предпочтителен** для лучшего сжатия
4. **JPG как fallback** для совместимости с старыми браузерами
5. **Качество**: 85-90% для WebP, 90-95% для JPG

## Автоматическая оптимизация:

Система автоматически:
- Определяет ориентацию фотографий
- Выбирает оптимальный layout (сетка или masonry)
- Подгружает изображения по мере прокрутки
- Адаптируется под размер экрана
