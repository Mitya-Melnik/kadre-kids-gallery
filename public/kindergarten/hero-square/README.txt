Положите здесь квадратные фото для слайдера на главном блоке страницы «Детский сад».

Структура и имена файлов:
- slide-1.webp, slide-2.webp, slide-3.webp — слайды для десктопа (1000x1000)
- slide-1-mobile.webp, slide-2-mobile.webp, slide-3-mobile.webp — мобильные версии (600x600)

Поддерживаются также форматы .jpg, .jpeg, .png как fallback если WebP отсутствует.

Размеры и формат:
- Десктопные: 1000x1000 пикселей (квадратные), 72 DPI
- Мобильные: 600x600 пикселей (квадратные), 72 DPI
- Изображения квадратные, подходящие для героического блока

Рекомендации:
- Формат WebP предпочтителен для лучшего сжатия
- Умеренное сжатие: слайды до ~300 KB для десктопа, до ~150 KB для мобильных
- Нумерация подряд (slide-1, slide-2, slide-3...)
- Если мобильная версия отсутствует, будет использована десктопная

Текущие изображения:
- slide-1: обложка макета "Цветные Карандаши"
- slide-2: обложка макета "Ушастики" 
- slide-3: обложка макета "Белочки"

Дополнительно:
- Первый слайд (slide-1) загружается приоритетно (eager loading)
- Остальные слайды загружаются по мере необходимости (lazy loading)
- Автоматическое переключение слайдов каждые 4 секунды
- Ручное переключение через индикаторы внизу слайдера
