Положите здесь фото для слайдера на главном блоке страницы «Детский сад».

Структура и имена файлов:
- slide-1.webp, slide-2.webp, slide-3.webp — слайды для десктопа (1200x500)
- slide-1-mobile.webp, slide-2-mobile.webp, slide-3-mobile.webp — мобильные версии (600x400)

Поддерживаются также форматы .jpg, .jpeg, .png как fallback если WebP отсутствует.

Размеры и формат:
- Десктопные: 1200x500 пикселей (соотношение 12:5), 72 DPI
- Мобильные: 600x400 пикселей (соотношение 3:2), 72 DPI
- Изображения горизонтальные, подходящие для героического блока

Рекомендации:
- Формат WebP предпочтителен для лучшего сжатия
- Умеренное сжатие: слайды до ~400 KB для десктопа, до ~200 KB для мобильных
- Нумерация подряд (slide-1, slide-2, slide-3...)
- Если мобильная версия отсутствует, будет использована десктопная

Дополнительно:
- Первый слайд (slide-1) загружается приоритетно (eager loading)
- Остальные слайды загружаются по мере необходимости (lazy loading)
- Автоматическое переключение слайдов каждые 4 секунды
- Ручное переключение через индикаторы внизу слайдера
