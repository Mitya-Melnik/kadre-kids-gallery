Положите здесь фото для макета «Совушки».

Структура и имена файлов:
- cover.webp (или cover.jpg / cover.png) — обложка макета (квадратная 1000x1000)
- cover-mobile.webp — мобильная версия обложки (600x600)
- 1.webp, 2.webp, 3.webp, ... — фото макетов (квадратные 1000x1000)  
- 1-mobile.webp, 2-mobile.webp, ... — мобильные версии фото (600x600)

Размеры и формат:
- Десктопные: 1000x1000 пикселей, 72 DPI
- Мобильные: 600x600 пикселей, 72 DPI
- Все изображения строго квадратные

Рекомендации:
- Формат WebP предпочтителен для лучшего сжатия
- Умеренное сжатие: обложка до ~200 KB, фото до ~300 KB
- Нумерация подряд (1,2,3...), пропуски допустимы — пропущенные номера будут скрыты

Дополнительно:
- Оптимально 12–24 фото на макет для удобного просмотра
- Модальный просмотр: мобильный — 2 колонки, планшет — 3, десктоп — 4
- Сетка макетов на странице: 1/2/3 макета в ряд (мобильный/планшет/десктоп)
